# Description

Implement navigation bar feature on top of the app.

### Requirements

- Navbar should be sticky on top as user scroll down
- Navbar consists of Danantara Logo, PLN Logo and list of menu links
- On mobile view, navbar will become sidebar :
  - will be triggered from icon action button
  - sidebar have slide in and out animation
  - have glass-style transparent UI
  - `Contact` menu link will become button UI
- Menu links will have underline with animation on hover
- Navbar have slight shadow effect on below
- Navbar background color : #e7ecef
- Font color : #274c77
- Font used are : Plus Jakarta Sans
- Underline color : #274c77
- Button background color : #a3cef1
