# Description

Implement stats section UI for landing page

### Requirements

- Stats section rendered below the hero section
- Use grid based UI with each individual stat contain :
  - Stat number :
    - font family: `Instrument Serif`
    - color: `#274c77`
    - bigger font size than stat label
    - This component divided to two parts:
      - `number` label which animated incrementally
      - `label` which at the side of `number` label
  - Stat label
    - font family: `Plus Jakarta Sans`
    - color: `#6096ba`
    - all letter capslock
- Stat number have incremental number animation and fade up show animation
- Stat label have fade up show animation
- There are small `since` info label at the bottom right of section
