# Description

Implement about us section UI for landing page

### Requirements

- About us section rendered below the stats section
- Contain two main columns : `informations` & `picture`
- `informations` columns contains :
  - top `About Us` label in capitalized letter
  - `title` label:
    - font family: `Instrument Serif`
    - color: `#274c77`
  - `subtitle` label:
    - font family: `Instrument Serif`
    - color: `#6096ba`
    - italic
  - `description` text
  - `badges` list section contains badge with icon and label
- Mobile view will change UI to columns with `picture` on top of `informations`
