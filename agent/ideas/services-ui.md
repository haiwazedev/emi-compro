# Description

Implement services UI for landing page

### Requirements

- Use stacked cards UI design
- Section have title at very top with `Instrument Serif` font
- Each cards contain:
  - Icon at the left
  - Title with `Instrument Serif` font
  - Badge beside the title
  - Description text with `Plus Jakarta Sans` font
  - Tags list with badge-style UI:
    - tag divided into 3 types:
      - plain tag: Only change background color when hovered
      - document tag: Show popup showing scrollable document when hovered (see UI reference)
      - link tag: Have icon & show popup showing scrollable document when hovered (see UI reference) & can be clicked to open related link in new tab
- Card have slight raised and shadow animation when hovered
- On mobile, layout inside card will become stacked column (see UI reference)
- Breakpoint used for mobile are `lg`

### Notes

- UI design references can be found at agent/resources/services-ui
