# Description

Implement Frequently Asked Question (FAQ) UI section on landing page

### Requirements

- Use stacked column-ui contains :
  - `header` area with title information
  - `questions` area with accordion UI component
- Use accordion to display the question with answer on expanded section :
  - accordion item use card-like ui with rounded border and space between items
  - bordered by box and scrollable
