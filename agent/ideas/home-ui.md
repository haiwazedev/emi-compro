# Description

Implement home UI section for landing page

### Requirements

- Home section should be at very top and overlap with navbar (navbar above the section)
- Navbar background will become transparent when focus on home section, but change to solid again when navbar area is hovered
- Home will contain carousel with slides following each hero section area
- Hero section area contains some information text:
  - Hero info badge - static
  - Hero title which contains :
    - main title - dynamic - big font size
    - subtitle with gradient colors - dynamic - italic with same size as main title
  - Hero description - dynamic
  - Action rows with two action buttons - static contain links to #services and #about
- Carousel slide will autoplay with no left/right button but with dots below to jump between slides
- Slide changes will have smooth fade animation for background image and hero section
- Mobile view (lg) layout will stay the same but with smaller text for responsive
- Hero title will use "Instrument Serif" font family
- Hero info badge show green dot (glowing animation) with #e5e7eb text color
